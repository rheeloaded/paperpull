    Welcome to PaperPull

    PaperPull saves your statements and receipts from the sites you choose, into a folder on this computer. First, where should they go?

    /data is the container's name for its data folder. On your server it is the folder named data inside the folder that holds compose.yaml, unless your compose.yaml points it somewhere else. Each provider you choose gets a folder of its own in there, and its documents go in that folder.

    Each provider you choose gets a folder of its own inside it. Nothing is downloaded until you ask.

    Which providers do you use?

    Pick any you have an account with. Each gets its own folder, and nothing downloads until you ask. You can add more later.

    None chosen yet

    Whose documents are these?

    The name on the account, as the provider writes it. It never leaves this computer. It is what lets PaperPull remove your name from a file before you send it to anyone, and it can go in your file names.

    Leave it blank to skip. A second person on the same provider is added later, from that provider's More menu.

    Moving from another computer?

    Bring its providers and download history with the file from Export history. Nothing you already have downloads again.

    Just looking?

    Open a sample archive of invented statements and receipts, to try Accounts and both spreadsheets. Nothing signs in and nothing of yours is touched.

    Already have PaperPull folders?

    Point to the folder that holds them, the one with Chase Statements, Amazon Receipts and so on inside it. Nothing is moved or copied.

    Accounts

      Spreadsheets

      Made from what PaperPull already saved, so nothing is downloaded. Each file is made fresh every time, so edit a copy.

      Purchases

      Every item you bought, one row each, from your receipts, newest first. Adds an Orders sheet and your spending per provider per year. It takes a second, and no PDF is opened.

      Format

      Bank transactions

      Every transaction inside your statement PDFs, one row each, with a sheet that says whether each statement adds up. Money in is positive and money out is negative, for a bank account and a card alike. A statement that does not add up is still included, with the difference shown.

      Format

      Reading statements

      The first time takes a few minutes for a big archive. Each statement is read once and remembered, so the next one takes seconds.

      Rename the files you already have to match?
      
        
      
        
      Preview first. It lists every file that would change and changes nothing. Renaming then does
          exactly that. Nothing is downloaded or deleted, a file moves only into or out of the folders a
          pattern with a / names, and each app's index follows its files, so nothing is ever downloaded
          twice. The preview can also list files an app would now describe better than when it saved
          them.
      
        
      
          
          
          
          
        
      
        
      
      
      
    
      
    
      
      Edit as text for people who prefer to write the pattern
      
      
      Written by hand, {date:yyyymmdd}[ - {provider}][ -- {number|kind}]
        is the date, then the provider, then the order number, or the kind when there is no number. Square
        brackets make a part that is skipped when empty, and {a|b} takes the first that has a value.
      
      
      A / puts files in folders, inside the folder each kind
        of document already goes to. {provider}/{year}/{date:yyyy-mm-dd} {summary} files each
        statement in a folder for its provider and one for its year. Every folder names a field, a folder
        whose fields are empty is left out, and a pattern goes at most three folders deep.

        Restore deleted files
        
        
        PaperPull remembers every document it saved, so it never downloads one twice, even after you delete
          the PDF, say once it is in paperless-ngx. Restore fetches the missing ones again, for the dates you pick.
        
    
        
      
        Which dates
        
        
          
        
            
        
          
        
        
        
        
          
          
        
        
        A year, or both a From and a To date, is needed, so a whole history is
          never fetched again by accident.
        
      
        
      
        How many
        
        
        
        
      
          
        
        • Nothing is overwritten. A file you still have stays as it is, and the app may save a second copy beside it, under a name of its own.
          • 
        
        • The provider is asked again for each document fetched, so a long range takes as long as the first download did.
          • 
        
        • For this run only. Your next Get new documents works as usual, and Continue never restores.

        Make a support report
        
        
        Diagnose reads the provider's page and writes two files to its Diagnostics folder, downloading
          nothing. The one whose name starts with survey- holds counts and states and no text from your account,
          and that is the one to attach to an issue. The detailed file beside it keeps a word only when it is on
          PaperPull's fixed list and writes any other as its shape, and a title, row or label only the words that say
          what kind of document and when, so a card's name never stays. It can go with it. A screenshot, where Diagnose
          takes one, shows the page as it is and stays on this machine.
        
    
        Sign in to the provider first and leave its window on the page that has your
      documents, so the report reads the right page.
        
    
        
      
        
  
        
        


  
        
    
        
      
        Record steps for support
        
        
        Record watches one signed-in page while you click your way to a document, and writes what you did to the
          Diagnostics folder. It downloads nothing and captures no keystroke. It is the one-round version of a support
          report, since a report guesses which control matters and a recording knows.
        
    
        Start it, click through the provider's site to one document in its window, then
      press Stop recording here.
        
    
        
      
        
  
        
        


  
        
    
        
      
        Before you start
        
        
        PaperPull reads your own accounts at the providers you choose. A few things to know first.
        
    
        
      
          
        
        • You sign in yourself, in a browser PaperPull opens. It never asks for the passwords to your accounts and sends nothing to PaperPull.
          • 
        
        • Use it only with accounts you are allowed to access. A provider's own rules may limit tools like this one, and a provider can lock an account it thinks is automated.
          • 
        
        • Check the original documents before you rely on a spreadsheet, and always before a tax filing. PaperPull can miss or misread a document.
          • 
        
        • Each provider's signed-in session is kept in a browser profile folder, and anyone who opens it can act as you. Keep the computer PaperPull runs on private, and never put PaperPull Server on the open internet.
          • 
        
        • PaperPull is free software with no warranty, and its liability is limited, as the terms say.
