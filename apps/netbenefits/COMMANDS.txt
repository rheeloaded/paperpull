NetBenefits STATEMENTS  -  commands   (READ-ONLY)
============================================================
Run these from the PaperPull folder (paperpull.bat on Windows,
./paperpull on macOS). login.bat is the one double-click that stays.

  Task            You                                 Spouse
  --------------  ----------------------------------  ----------------------------------
  Sign in         login.bat                           login.bat spouse
  Look (no d/l)   paperpull netbenefits diagnose            paperpull netbenefits diagnose --account spouse
  Pilot (test)    paperpull netbenefits pilot               paperpull netbenefits pilot --account spouse
  Full run        paperpull netbenefits all                 paperpull netbenefits all --account spouse
  Continue        paperpull netbenefits resume              paperpull netbenefits resume --account spouse
  Re-check PDFs   paperpull netbenefits verify              paperpull netbenefits verify --account spouse

FLOW:  login.bat  ->  paperpull netbenefits diagnose  ->  paperpull netbenefits pilot  ->  paperpull netbenefits all
Sign in, open your Documents/Statements area, keep the browser OPEN,
do the 2FA yourself.

READ-ONLY: downloads participant statements and tax forms only. It
NEVER moves money between funds, changes contributions, withdraws,
takes a loan, changes beneficiaries, or changes any setting.

Scope: quarterly and annual participant statements + 1099-R.
Tax forms contain your SSN - handle accordingly.

Your files: this folder (Statements\, Tax Documents\).
Spouse's:  "NetBenefits Statements - spouse".
Full command reference: COMMANDS.txt in the parent folder.
