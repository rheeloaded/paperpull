WEALTHFRONT DOCUMENTS  -  commands   (READ-ONLY)
============================================================
Run these from the PaperPull folder (paperpull.bat on Windows,
./paperpull on macOS). login.bat is the one double-click that stays.

  Task            You                                 Spouse
  --------------  ----------------------------------  ----------------------------------
  Sign in         login.bat                           login.bat spouse
  Look (no d/l)   paperpull wealthfront diagnose      paperpull wealthfront diagnose --account spouse
  Pilot (test)    paperpull wealthfront pilot         paperpull wealthfront pilot --account spouse
  Full run        paperpull wealthfront all           paperpull wealthfront all --account spouse
  Continue        paperpull wealthfront resume        paperpull wealthfront resume --account spouse
  Re-check PDFs   paperpull wealthfront verify        paperpull wealthfront verify --account spouse

FLOW:  login.bat  ->  paperpull wealthfront pilot  ->  paperpull wealthfront all
Sign in, open your Documents page, keep the browser OPEN, do the 2FA
yourself.

READ-ONLY: downloads statements and tax forms only. It never transfers
money, trades, rebalances, or changes any account setting.
Scope: statements + tax documents (1099s etc.). Tax forms contain your
SSN - handle accordingly.

Your files: this folder (Statements\, Tax Documents\).
Spouse's:  "Wealthfront Receipts - spouse".
Full command reference: COMMANDS.txt in the parent folder.
