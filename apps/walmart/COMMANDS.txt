WALMART RECEIPTS  -  commands
============================================================
Run these from the PaperPull folder (paperpull.bat on Windows,
./paperpull on macOS). login.bat and review_names.bat are the double-clicks that stay.

  Task            You                                 Spouse
  --------------  ----------------------------------  ----------------------------------
  Sign in         login.bat                           login.bat spouse
  Pilot (test)    paperpull walmart pilot             paperpull walmart pilot --account spouse
  Full run        paperpull walmart all               paperpull walmart all --account spouse
  Online only     paperpull walmart online            paperpull walmart online --account spouse
  In-store only   paperpull walmart instore           paperpull walmart instore --account spouse
  Continue        paperpull walmart resume            paperpull walmart resume --account spouse
  Re-check PDFs   paperpull walmart verify            paperpull walmart verify --account spouse
  Fix a name      review_names.bat                    review_names.bat spouse

FLOW:  login.bat  ->  paperpull walmart pilot  ->  paperpull walmart all
Keep the sign-in browser OPEN during the run (Walmart signs you
out the moment it closes). If "Robot or human?" appears, solve it
yourself in the window, then let the tool continue.
Your files: this folder.   Spouse's: "Walmart Receipts - spouse".
Full command reference: COMMANDS.txt in the parent folder.
