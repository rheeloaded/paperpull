DKB DOCUMENTS  -  commands   (READ-ONLY)
============================================================
Run these from the PaperPull folder (paperpull.bat on Windows,
./paperpull on macOS). login.bat is the one double-click that stays.

  Task            You                                 Spouse
  --------------  ----------------------------------  ----------------------------------
  Sign in         login.bat                           login.bat spouse
  Look (no d/l)   paperpull dkb diagnose            paperpull dkb diagnose --account spouse
  Pilot (test)    paperpull dkb pilot               paperpull dkb pilot --account spouse
  Full run        paperpull dkb all                 paperpull dkb all --account spouse
  Continue        paperpull dkb resume              paperpull dkb resume --account spouse
  Re-check PDFs   paperpull dkb verify              paperpull dkb verify --account spouse

FLOW:  login.bat  ->  paperpull dkb diagnose  ->  paperpull dkb pilot  ->  paperpull dkb all
Sign in, confirm the login in the DKB app yourself, open the Postfach,
keep the browser OPEN.

READ-ONLY: downloads the PDFs in the DKB Postfach only. It NEVER
transfers money, sets up a standing order, buys or sells securities,
changes a limit, locks a card, marks a message read, or changes any
setting.

Scope: Kontoauszuege, Kreditkartenabrechnungen, Wertpapierdokumente,
Steuerbescheinigungen, Vertragsinformationen, Mitteilungen.
Statements and tax documents contain your IBAN and tax data - handle
accordingly.

Your files: this folder (Kontoauszuege\, Wertpapierdokumente\, ...).
Spouse's:  "DKB Statements - spouse".
Full command reference: COMMANDS.txt in the parent folder.
