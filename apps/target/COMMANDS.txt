TARGET RECEIPTS  -  commands
============================================================
Run these from the PaperPull folder (paperpull.bat on Windows,
./paperpull on macOS). login.bat is the one double-click that stays.

  Task            You                                 Spouse
  --------------  ----------------------------------  ----------------------------------
  Sign in         login.bat                           login.bat spouse
  Pilot (test)    paperpull target pilot              paperpull target pilot --account spouse
  Full run        paperpull target all                paperpull target all --account spouse
  Online only     paperpull target online             paperpull target online --account spouse
  In-store only   paperpull target instore            paperpull target instore --account spouse
  Continue        paperpull target resume             paperpull target resume --account spouse
  Re-check PDFs   paperpull target verify             paperpull target verify --account spouse
  Fix a name      paperpull target review-names       paperpull target review-names --account spouse

FLOW:  login.bat  ->  paperpull target pilot  ->  paperpull target all
Keep the sign-in browser OPEN during the run.
Your files: this folder.   Spouse's: "Target Receipts - spouse".
Full command reference: COMMANDS.txt in the parent folder.
