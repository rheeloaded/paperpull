GAP RECEIPTS  -  commands
============================================================
Run these from the PaperPull folder (paperpull.bat on Windows,
./paperpull on macOS). login.bat is the one double-click that stays.

  Task            You                                 Spouse
  --------------  ----------------------------------  ----------------------------------
  Sign in         login.bat                           login.bat spouse
  Pilot (test)    paperpull gap pilot                 paperpull gap pilot --account spouse
  Full run        paperpull gap all                   paperpull gap all --account spouse
  Continue        paperpull gap resume                paperpull gap resume --account spouse
  Re-check PDFs   paperpull gap verify                paperpull gap verify --account spouse
  Fix a name      paperpull gap review-names          paperpull gap review-names --account spouse

FLOW:  login.bat  ->  paperpull gap pilot  ->  paperpull gap all
Online orders land in Online\, in-store purchases in In-Store\.
Keep the sign-in browser OPEN during the run.

HOW FAR BACK: Gap only shows about the LAST 13 MONTHS of orders, and every
one of them loads onto a single page - so a full run simply takes whatever
Gap still has. Older orders are gone from the site and cannot be downloaded.
To narrow a run, set "default_start_date" in the config or pass a date:
   .venv\Scripts\python.exe gap_receipts.py --all --start-date 2026-01-01

Your files: this folder.   Spouse's: "Gap Receipts - spouse".
Full command reference: COMMANDS.txt in the parent folder.
