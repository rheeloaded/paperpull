AMAZON RECEIPTS  -  commands
============================================================
Run these from the PaperPull folder (paperpull.bat on Windows,
./paperpull on macOS). login.bat is the one double-click that stays.

  Task            You                                 Spouse
  --------------  ----------------------------------  ----------------------------------
  Sign in         login.bat                           login.bat spouse
  Pilot (test)    paperpull amazon pilot              paperpull amazon pilot --account spouse
  Full run        paperpull amazon all                paperpull amazon all --account spouse
  Continue        paperpull amazon resume             paperpull amazon resume --account spouse
  Re-check PDFs   paperpull amazon verify             paperpull amazon verify --account spouse
  Fix a name      paperpull amazon review-names       paperpull amazon review-names --account spouse

FLOW:  login.bat  ->  paperpull amazon pilot  ->  paperpull amazon all
Keep the sign-in browser OPEN during the run.

DATE CUTOFFS (built into each config - you never type a date):
   You     = orders placed on/after 2025-01-01
   Spouse  = orders placed on/after 2023-08-20
To grab everything for an account, override once, e.g.:
   .venv\Scripts\python.exe amazon_receipts.py --all --config config.spouse.json --start-date 2000-01-01

Your files: this folder.   Spouse's: "Amazon Receipts - spouse".
Full command reference: COMMANDS.txt in the parent folder.
