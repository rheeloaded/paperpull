ANTHEM BCBS EOBs  -  commands   (READ-ONLY)
============================================================
Run these from the PaperPull folder (paperpull.bat on Windows,
./paperpull on macOS). login.bat is the one double-click that stays.

  Task            You                                 Spouse
  --------------  ----------------------------------  ----------------------------------
  Sign in         login.bat                           login.bat spouse
  Look (no d/l)   paperpull anthem diagnose           paperpull anthem diagnose --account spouse
  Pilot (test)    paperpull anthem pilot              paperpull anthem pilot --account spouse
  Full run        paperpull anthem all                paperpull anthem all --account spouse
  Continue        paperpull anthem resume             paperpull anthem resume --account spouse
  Re-check PDFs   paperpull anthem verify             paperpull anthem verify --account spouse

FLOW:  login.bat  ->  paperpull anthem diagnose  ->  paperpull anthem pilot  ->  paperpull anthem all
login.bat opens www.anthem.com/account-login. Sign in, do the 2FA
yourself (check "remember this device"); Anthem sends you to
membersecure.anthem.com - open the EOB Center there, keep it OPEN.

READ-ONLY: downloads Explanation of Benefits (EOB) PDFs only. It NEVER
changes a PCP, refills a prescription, appeals a claim, enrolls in
paperless, pays a premium, messages care teams, or changes any setting.
Every EOB is fetched by the portal's own API - nothing on the page is
clicked.

Scope: Medical, Pharmacy and Chiropractic EOBs (and EOB Checks), plus a
1095-B tax form if the account has one. EOBs are Protected Health
Information - handle accordingly.

Your files: this folder (EOBs\, Tax Documents\).
Full command reference: COMMANDS.txt in the parent folder.
